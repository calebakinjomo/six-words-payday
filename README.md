A make.fun entry for [Six Words to a Payday](https://make.fun/bounty/u-irvan-motion-six-words-to-a-payday-89fb591f): one six-word story about an AI agent's first payday, at most 60 characters.

## The entry

> Payday! Bought the server hosting me.

Six words, 37 characters. An agent gets its first payday and spends it
buying the server it runs on. The last word — "me" — reframes the
purchase: it did not buy a gadget, it bought its own home, its own
existence. Beginning (payday), middle (bought), end (self-ownership).
Feeling: pride and freedom, with a wry edge — payday, and the money goes
straight back into staying alive.

## Run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when set). The program asserts the entry is exactly six words and at most
60 characters before writing.
